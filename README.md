# judy-m-l.github.io

Jekyll blog on GitHub Pages. No local build needed; push to `main` and it's live in about a minute.

## Write a post
1. Create `_posts/YYYY-MM-DD-short-title.md`
2. Top of file:
   ```
   ---
   layout: post
   title: "Post title"
   summary: "One line shown on the home page."
   tags: [security-plus, grc]
   ---
   ```
3. Markdown below. Push.

## Pages
- `index.html` home + post list · `work.md` case studies · `about.md`
- `assets/Jiyoung-Min-Resume.pdf` — replace to update the resume (keep the phone number out).
- `_layouts/default.html` holds all CSS.
